## ⏱️ 4. โครงสร้างการนำเสนอใน VDO (ความยาวรวมไม่เกิน 3 นาที)

> **กฎเหล็กจากโจทย์:**
> 1. ความยาว **ไม่เกิน 3 นาที**
> 2. **เห็นหน้าสมาชิกทุกคน** ในวิดีโอ
> 3. **ทุกคนต้องได้นำเสนอ** (แบ่งพาร์ทกันพูด)
> 4. **ไม่ต้องแนะนำตัว** ให้ใส่ชื่อ+รหัสไว้ในสไลด์ เพื่อประหยัดเวลา

### แผนแบ่งเวลาและบทพูด (แนะนำ):

- **นาทีที่ 0:00 - 0:40 (สมาชิกคนที่ 1): หัวข้อภาพและกระบวนการเตรียมข้อมูล**
  - **สไลด์หน้า 1-2:** แนะนำโจทย์ "Image Colorization แปลงภาพลายเส้นเป็นภาพสี"
  - อธิบายหัวข้อภาพ: วาดวัตถุธรรมชาติ 3 ชนิด (แอปเปิ้ล, แครอท, ดอกไม้) รวม 60 คู่ภาพ โดยสร้างภาพสเก็ตและลงสีเอง 100%
  - การเตรียมข้อมูล: ปรับขนาดภาพเป็น 128x128, แปลงเป็น RGB และ Normalization ค่าพิกเซลเป็น [-1, 1]

- **นาทีที่ 0:41 - 1:40 (สมาชิกคนที่ 2): การแบ่ง Train/Test และสถาปัตยกรรมโมเดล**
  - **สไลด์หน้า 3-4:** การแบ่งข้อมูล Train 80% (48 ภาพ) และ Test 20% (12 ภาพ)
  - โมเดลที่เลือก: **U-Net Architecture**
    - Encoder สกัด Feature จากภาพสเก็ต
    - Decoder ทำการ Upsampling เพื่อสร้างภาพสี
    - มี **Skip Connections** ช่วยส่งผ่านเส้นขอบความละเอียดสูง ทำให้ภาพสีคมชัด ไม่เบลอ
  - Loss Function: **L1 Loss (MAE)** ร่วมกับ **Adam Optimizer**

- **นาทีที่ 1:41 - 2:50 (สลับกันพูดหรือสมาชิกคนที่ 1 ต่อคนที่ 2): การวัดประสิทธิภาพและผลลัพธ์**
  - **สไลด์หน้า 5-6:** กราฟ Loss Curve (การลู่เข้าของ Train และ Test Loss)
  - ค่าการวัดผล: ค่า MAE และ PSNR (Peak Signal-to-Noise Ratio)
  - แสดงภาพเปรียบเทียบ 3 ช่อง: `Input Sketch` ➔ `Model Output (ภาพที่เติมสี)` ➔ `Ground Truth (ภาพจริง)`
  - สรุปผล: โมเดลสามารถจับคู่ประเภทวัตถุและลงสีได้ถูกต้องตามโครงสร้างลายเส้น
